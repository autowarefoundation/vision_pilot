Capabilities

Entry-level L2, done properly

Vision Pilot targets the in-lane autonomous driving feature set that automotive OEMs and Tier-1 suppliers ship in series production passenger cars.

ACCAutonomous cruise controlLongitudinal control that holds a safe gap to the closest in-path object.
FCWForward collision warningAlerts the driver when a collision with the lead object becomes imminent.
AEBAutonomous emergency brakingApplies braking automatically when the warning is not acted on.
LKASLane keep assistLateral control that centres the vehicle on the estimated ego path.
LDWLane departure warningFlags unsignalled drift across a lane boundary, left or right.
ISAIntelligent speed assistMap-based — keeps the commanded speed within the applicable limit.
LDALane departure avoidanceSteers back into lane rather than only warning about the drift.
ALKAutonomous lane keepSustained in-lane lateral control on top of LKAS.
AutopilotSingle-lane hands-free highway autopilotCombined longitudinal and lateral control for highway driving, built on the feature set above.
Hands-free autopilot has a defined operational domain. It is available only on highways and motorways with clearly marked lane lines, in fair weather and visibility, across the full range of highway speeds (0–70 mph), and away from construction zones and roadwork objects. A human driver must monitor and supervise the system at all times.
Architecture

Hybrid end-to-end AI

Camera frames are processed in parallel by perception models for safety and by an end-to-end model for performance. A Safety Guardian fuses both paths before anything reaches the planner.

Perception

AutoSpeed ↗

Closest in-path object detection — what is in front of you, and how far away it is.

 Perception

AutoSteer ↗

Ego path future waypoint detection — the drivable corridor ahead of the vehicle.

 End to end

AutoDrive ↗

Distance and in-path object presence detection, plus road curvature estimation.
🗺️

No HD maps

Vision Pilot operates fully mapless, following the road in real time. No localisation stack, no map maintenance, no geofence to keep current.

📷

One monocular camera

A single front-facing RGB camera with 50–55° horizontal FoV at 2 MP. That is the entire sensor specification.

Quick start

Three ways to run it

Sample OpenLane data is provided so you can see the full pipeline in action before touching a vehicle or a camera.

Best if you intend to modify the stack. Requires ONNX Runtime.

git clone https://github.com/autowarefoundation/vision_pilot.git
cd vision_pilot/VisionPilot
mkdir build && cd build

cmake -DONNXRUNTIME_ROOT=<ONNX_RUNTIME_ROOT_PATH> ../
make -j$(nproc)

./VisionPilot

Add -DENABLE_ROS2_INTERFACE=ON for ROS 2, or -DENABLE_OCCUPANCY=ON for the bird's-eye Occupancy window.

Best on a fresh machine — the package pulls in the CUDA dependencies for you.

sudo apt install ./VisionPilot-1.0-x86_64.deb
# reboot, then:
VisionPilot

Config lives in /usr/share/visionpilot/config for package installs.

Best for a reproducible environment. GPU/CPU and ROS 2 variants are all built from the same scripts.

cd VisionPilot/docker

./build.sh --gpu --ros2      # or --cpu, and optionally --occupancy
./run.sh   --gpu --ros2

Edit config/*.conf before building — the config is baked into the image.
